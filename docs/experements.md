### Setting up the new version of "Erudios"
- Created a new git repository
- Initialized uv (virtual environment) -> `uv init`
- created a project venv (`uv venv`)
- Activated uv -> `.venv\Scripts\activate`
- Initialized project folders (backend, database, frontend, docs, evals)
- Created .env & .env.example files
- Created .gitignore file
- Created README.md file
